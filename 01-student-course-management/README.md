# Student Course Management

DBMS/SQL program demonstrating student and course management operations using tables, queries, views, functions, triggers, and indexes.

## Tables Used

### Student
- ID
- Name
- Age
- Department
- Marks

### Course
- CourseID
- CourseName
- StudentID

## Operations Performed

1. Create Student and Course tables.
2. Insert at least 5 records into each table.
3. Find students with marks greater than 80.
4. Find students belonging to the MCA department.
5. Find students whose names start with 'A'.
6. Find departments with average marks greater than 75.
7. Find students who are not enrolled in any course.
8. Create a view for students with marks greater than 75.
9. Write a function to calculate grade.
10. Write a trigger for automatic update on insert.
11. Create an index on student name.
12. Count students in each department having more than 2 students.
